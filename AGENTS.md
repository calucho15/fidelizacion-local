# Regla de Localización Permanente: Venezuela (Guanare, Portuguesa) 🇻🇪
Este proyecto está ubicado y diseñado para el mercado de **Venezuela** (ciudad piloto: **Guanare, Estado Portuguesa**).
- **Idioma y Tono:** Español venezolano profesional (tú: tienes, puedes, ingresa, prueba, quieres, llévate, mesonero). NUNCA usar lunfardo o modismos argentinos ("sos", "tenés", "podés", "mozo", etc.).
- **Moneda:** Economía bimonetaria. Referencia en Dólares ($ USD) y pagos cotidianos en Bolívares (Bs.) calculados a la Tasa Oficial BCV. Medios: Pago Móvil, Punto de Venta, Efectivo $. NUNCA usar pesos.
- **Teléfonos:** Código país `+58`, prefijos móviles venezolanos `0412`, `0414`, `0424`, `0416`, `0426`.
- **Referencia Completa:** Consulta `CONTEXTO_VENEZUELA.md` para más detalles.
